01

What is VS Code

C'est quoi VS Code ?

VS Code is a free code editor.VS Code est un éditeur de code gratuit.

It works on Windows, Mac and Linux.Il fonctionne sur Windows, Mac et Linux.

  1. 1
    Explorer: your files.Explorateur : tes fichiers.
  2. 2
    Editor: where you write code.Éditeur : là où tu écris ton code.
  3. 3
    Terminal: where you type commands.Terminal : là où tu tapes des commandes.
  4. 4
    Source Control: Git, built in.Contrôle de code source : Git, intégré.
02

Install VS Code

Installer VS Code
  1. 1
    Go to code.visualstudio.comVa sur code.visualstudio.com
  2. 2
    Click the download button for your system.Clique sur le bouton de téléchargement pour ton système.
  3. 3
    Windows: run the installer. Keep "Add to PATH" checked.Windows : lance l'installateur. Garde « Add to PATH » coché.
  4. 4
    Mac: unzip it and drag the app to Applications.Mac : décompresse et glisse l'app dans Applications.
  5. 5
    Open VS Code. You are ready.Ouvre VS Code. Tu es prêt.
03

Install Git

Installer Git
  1. 1
    Windows: download Git from git-scm.comWindows : télécharge Git sur git-scm.com
  2. 2
    Run it. Keep the default options.Lance-le. Garde les options par défaut.
  3. 3
    Mac: type git --version in the terminal. Click Install if asked.Mac : tape git --version dans le terminal. Clique sur Installer si demandé.
  4. 4
    Check it works in VS Code. Open the terminal with Ctrl+`Vérifie dans VS Code. Ouvre le terminal avec ce raccourci.
  5. 5
    Tell Git your name and email. Only once.Donne ton nom et ton courriel à Git. Une seule fois.
04

What is GitHub

C'est quoi GitHub ?

Git tracks every change in your project.Git garde l'historique de chaque changement.

GitHub keeps your project online.GitHub garde ton projet en ligne.

Your whole team works on the same code.Toute ton équipe travaille sur le même code.

Think of a video game. Git saves your progress. GitHub is the cloud save. Pense à un jeu vidéo. Git sauvegarde ta progression. GitHub, c'est la sauvegarde dans le cloud.
05

Create a GitHub account

Créer un compte GitHub
  1. 1
    Go to github.com and click Sign up.Va sur github.com et clique sur Sign up.
  2. 2
    Enter your email, a password and a username.Entre ton courriel, un mot de passe et un nom d'utilisateur.
  3. 3
    Click Create account and solve the quick puzzle.Clique sur Create account et résous le petit casse-tête.
  4. 4
    Enter the code sent to your email.Entre le code reçu par courriel.
Pick a clean username. It will be on your CV one day. Choisis un nom d'utilisateur sérieux. Il sera sur ton CV un jour.
06

Create a repository

Créer un dépôt

A repository (repo) is your project folder, with its full history.Un dépôt (repo), c'est le dossier de ton projet, avec tout son historique.

  1. 1
    Click + at the top right, then New repository.Clique sur + en haut à droite, puis New repository.
  2. 2
    Give it a name.Donne-lui un nom.
  3. 3
    Choose Public or Private.Choisis Public ou Private.
  4. 4
    Turn on Add README.Active Add README.
  5. 5
    Click Create repository.Clique sur Create repository.
06

Invite your team

Invite ton équipe
  1. 1
    Open your repo, then click Settings.Ouvre ton dépôt, puis clique sur Settings.
  2. 2
    Click Collaborators.Clique sur Collaborators.
  3. 3
    Click Add people. Type their username.Clique sur Add people. Tape leur nom d'utilisateur.
  4. 4
    They accept the invite by email.Ils acceptent l'invitation par courriel.
Only one person creates the repo. Everyone else clones it. Une seule personne crée le dépôt. Les autres le clonent.
07

Clone a repo

Cloner un dépôt

Cloning copies the repo from GitHub to your computer.Cloner copie le dépôt de GitHub vers ton ordinateur.

  1. 1
    On GitHub, click Code and copy the URL.Sur GitHub, clique sur Code et copie l'URL.
  2. 2
    In VS Code, press Ctrl+Shift+P. Mac: Cmd+Shift+PDans VS Code, appuie sur ce raccourci.
  3. 3
    Type Git: Clone. Paste the URL.Tape Git: Clone. Colle l'URL.
  4. 4
    Pick a folder, then click Open.Choisis un dossier, puis clique sur Open.
08

Create a branch

Créer une branche

A branch is your own copy. You can work without breaking main.Une branche, c'est ta copie. Tu travailles sans briser main.

  1. 1
    Click the branch name, bottom left.Clique sur le nom de la branche, en bas à gauche.
  2. 2
    Choose Create new branch.Choisis Create new branch.
  3. 3
    Type a name, like feature/navbar. Press Enter.Tape un nom, comme feature/navbar. Appuie sur Entrée.
One branch per feature. One person per branch. Une branche par fonctionnalité. Une personne par branche.
09

Commit your work

Faire un commit

A commit is a save point with a short message.Un commit, c'est un point de sauvegarde avec un court message.

  1. 1
    Open Source Control. Ctrl+Shift+GOuvre le contrôle de code source.
  2. 2
    Click + next to a file to stage it.Clique sur + à côté d'un fichier pour l'indexer (stage).
  3. 3
    Write a short message.Écris un court message.
  4. 4
    Click Commit.Clique sur Commit.
Good message: "Add contact form". Bad message: "stuff". Bon message : « Add contact form ». Mauvais message : « trucs ».
09

Push to GitHub

Envoyer sur GitHub (push)

Push sends your commits from your computer to GitHub.Push envoie tes commits de ton ordinateur vers GitHub.

  1. 1
    After your first commit, click Publish Branch.Après ton premier commit, clique sur Publish Branch.
  2. 2
    After that, click Sync Changes.Ensuite, clique sur Sync Changes.
  3. 3
    First time only: click Allow and sign in to GitHub.La première fois : clique sur Allow et connecte-toi à GitHub.
  4. 4
    Refresh GitHub. Your branch is there.Rafraîchis GitHub. Ta branche est là.
10

Open a pull request

Ouvrir une pull request

A pull request (PR) asks your team to add your branch to main.Une pull request (PR) demande à ton équipe d'ajouter ta branche à main.

  1. 1
    On GitHub, click Compare & pull request.Sur GitHub, clique sur Compare & pull request.
  2. 2
    Check: base is main, compare is your branch.Vérifie : base est main, compare est ta branche.
  3. 3
    Write a title and what you changed.Écris un titre et ce que tu as changé.
  4. 4
    Click Create pull request.Clique sur Create pull request.
10

Review and merge

Réviser et fusionner (merge)
  1. 1
    A teammate opens Files changed and reads the code.Un coéquipier ouvre Files changed et lit le code.
  2. 2
    They click Review changes.Il clique sur Review changes.
  3. 3
    They pick Approve, then Submit review.Il choisit Approve, puis Submit review.
  4. 4
    Click Merge pull request, then Confirm merge.Clique sur Merge pull request, puis Confirm merge.
After the merge, delete the branch. It is done. Après la fusion, supprime la branche. C'est fini.
11

Pull the latest changes

Récupérer les derniers changements

Pull brings your team's new code to your computer.Pull ramène le nouveau code de ton équipe sur ton ordinateur.

  1. 1
    Click the branch name. Switch to main.Clique sur le nom de la branche. Passe sur main.
  2. 2
    In Source Control, click ... then Pull.Dans le contrôle de code source, clique sur ... puis Pull.
  3. 3
    Or click the sync arrows at the bottom.Ou clique sur les flèches de synchro en bas.
Pull before you start working. Every time. Fais un pull avant de commencer. Chaque fois.
Same line changed by two people? That is a conflict. Ask a mentor. Même ligne changée par deux personnes ? C'est un conflit. Demande à un mentor.
12

Stash your work

Mettre ton travail de côté (stash)

Stash puts unfinished work aside, so you can switch branches.Stash met ton travail pas fini de côté, pour changer de branche.

  1. 1
    In Source Control, click ... then Stash.Dans le contrôle de code source, clique sur ... puis Stash.
  2. 2
    Choose Stash. Your changes are put aside.Choisis Stash. Tes changements sont mis de côté.
  3. 3
    Do your other task.Fais ton autre tâche.
  4. 4
    Come back. Choose Pop Latest Stash.Reviens. Choisis Pop Latest Stash.
Pop brings your work back. Pop ramène ton travail.
